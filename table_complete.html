HTML Table Elements Example

Table Structure Explanation:

  • <table> - Container for the entire table
  • <tr> - Table Row (contains <th> or <td>)
  • <th> - Table Header (bold, typically used in first row)
  • <td> - Table Data (regular cell data)

Complete Table Example:

Student Name Roll Number Subject Marks
Shreyas Kumbhar 101 Mathematics 95
Aarav Patel 102 Science 88
Priya Singh 103 English 92
Vikram Sharma 104 History 85
Ananya Gupta 105 Geography 90

HTML Code:

<table>
    <tr>
        <th>Student Name</th>
        <th>Roll Number</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>
    <tr>
        <td>Shreyas Kumbhar</td>
        <td>101</td>
        <td>Mathematics</td>
        <td>95</td>
    </tr>
    <tr>
        <td>Aarav Patel</td>
        <td>102</td>
        <td>Science</td>
        <td>88</td>
    </tr>
    <tr>
        <td>Priya Singh</td>
        <td>103</td>
        <td>English</td>
        <td>92</td>
    </tr>
</table>
